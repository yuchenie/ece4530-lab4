LAB 4 VALIDATION FILES

Contents
--------
reference/input.scs       Netlist of the validated circuit and DC/AC testbench.
reference/ade_e.scs       Auxiliary include generated by ADE.
recorded/                Device properties, measurements and completion status
                         from the November 15 validated run.
run_validation.py        Generates the DC/AC, output-resistance, sine-swing
                         and closed-loop step testbenches; optionally runs them.
extract.ocn              Extracts measurements from the generated Spectre PSF.

Requirements
------------
Cadence Spectre and the gpdk045 PDK must be installed locally.
The PDK and license files are not included in this repository.
The reference uses Cornell's installed gpdk045 model path.
Python 3.6 or newer is sufficient.

Run from the repository root
---------------------------
    python3 validation/run_validation.py

Output goes to validation/runs/ (ignored by Git).
The default run executes 11 cases: DC/AC plus the 10 standalone checks
described in HANDOFF.txt. A nonzero exit code indicates a failed simulation.

Useful options:
    python3 validation/run_validation.py --case dcac
    python3 validation/run_validation.py --prepare-only
    python3 validation/run_validation.py --model /path/to/gpdk045.scs
    python3 validation/run_validation.py --netlist /path/to/ADE/netlist/input.scs
    python3 validation/run_validation.py --output /path/to/new/results

Set SPECTRE or use --spectre if the simulator is not on PATH.
The output directory is reused if it already exists; use a new --output
directory when you want to preserve an earlier run.

Read the results in Cadence
--------------------------
After running all cases, enter these commands in the Virtuoso CIW,
replacing <netid> and the checkout location as needed:

    lab4ValidationResults = "/home/<netid>/ece4530/lab4/validation/runs"
    load("/home/<netid>/ece4530/lab4/validation/extract.ocn")

The script writes validation_metrics.txt in the results directory.
It uses the 1 uV reference for its compression column; see HANDOFF.txt
for the distinction from the 10 uV reference used in the summary.

The supplied reference is a fixed snapshot of the validated circuit.
Changing an OA schematic does not automatically update this snapshot.
After a circuit change, regenerate the ADE netlist and pass its input.scs
with --netlist, or deliberately replace the reference files.

Maestro use
-----------
Open lab4_testbench/schematic and Check and Save, then open its maestro view.
The stored projectDir is a per-user ADE runtime path from the original
session. Select a writable simulation directory under your own account
before running; do not use another user's /home path.
Use HANDOFF.txt for the test conditions and measured results.
